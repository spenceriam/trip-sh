# Project-Specific MCP Recommendations

Use this guide to choose appropriate MCP servers based on project type.

## Web Applications

- Chrome DevTools MCP (required) for browser automation, debugging, and UI testing.
- Context7 MCP (recommended) for framework and library documentation lookup.
- Database MCP if the application interacts with a database.

## CLI Tools

- Filesystem MCP for interacting with local files and directories.
- Context7 MCP for documentation and reference material.

## API Projects

- HTTP testing MCP for exercising API endpoints.
- Database MCP for direct interaction with backing stores.

## Mobile Applications

- Platform-specific debugging MCPs for iOS, Android, or cross-platform frameworks.

During the planning phase, identify which MCPs are needed and ensure they are configured before implementation begins.
